# 公众号工作台使用指南

解决公众号文章排版麻烦、配图封面上传繁琐、发布信息重复填写的问题。在本地编辑 HTML、调整图片，复制公众号兼容格式，或将正文和图片一起保存到草稿箱，再到公众号后台预览发布。

这份指南介绍安装、打开文章、调整图片、复制排版和创建草稿的具体操作。

## 安装与开始

准备好下面的环境。

- Windows 10 或 Windows 11
- 支持插件的 Codex 应用或 Codex CLI
- Python 3.10+，能够运行 `python` 或 `py`
- Windows PowerShell 或 PowerShell 7

进入包含 `.agents` 和 `plugins` 的项目根目录，运行安装命令。

```powershell
python -m pip install -r ".\plugins\wechat-publishing-workflow\requirements.txt"
codex plugin marketplace add .
codex plugin add wechat-publishing-workflow@personal
```

新建一个 Codex 任务，使用 `$wechat-html-editor` 开始处理文章。如果技能列表尚未刷新，可以重启 Codex。使用 `py` 的电脑，可将安装命令里的 `python` 换成 `py -3`。

本项目的插件集名称是 `personal`。已经配置了其他同名插件集时，先核对来源，保留现有配置。

## 打开文章，调整排版

把文章 HTML 的路径交给 Codex，使用本地编辑器查看和修改。

```text
使用 $wechat-html-editor 打开这份 HTML。
保留现有排版，让我在浏览器里修改正文、替换图片。
```

打开后直接点击正文编辑，选中图片即可调整大小、位置和对齐方式。文字修改和图片调整都会保存到本地 HTML，检查完成后即可复制正文或创建草稿。

已有 HTML 可以交给编辑器继续使用。文件采用 UTF-8 编码，正文区域包含 `<article>`、`id="article"` 或 `<main>` 即可。把标题放在正文区域之外，复制时就能分别处理标题和正文。

### 文件保存在哪里

新建文章未指定路径时，默认保存在当前工作目录。

```text
YYYY-MM-DD-标题\标题.html
```

可在当前工作目录的 `.wechat-publishing.json` 中配置文章根目录：

```json
{"article_dir": "公众号文章"}
```

相对目录以当前工作目录为基准，也支持绝对目录。没有配置时不添加 `公众号文章` 这一层。配置格式错误会报错。

给了具体文件路径，就优先保存到指定位置；该位置已存在时拒绝覆盖。打开已有文件，会继续修改原文件。默认路径遇到同名的新文章，会通过 `-v2`、`-v3` 等版本号区分。标题优先使用已确认标题，否则从 HTML 的 `h1`、`title` 依次提取，最后才使用“未命名文章”。新建文件统一由技能中的 `scripts/create_article.py` 处理。

## 修改文字与图片

### 文字边改边保存

停止输入约 1 秒后，编辑器会把修改写回 HTML。顶部状态栏显示保存进度和结果，`Ctrl+S` 可以立即保存。

每次启动编辑器后的第一次保存，会创建 `文章.html.bak` 原始备份。同一编辑会话内继续保存，这份备份保持不变。页面有尚未保存的修改时，关闭或刷新会出现提醒。

### 图片看着调

点击 `插入图片`，在文章中加入配图。选中图片后，工具栏会显示这些操作。

- 替换图片
- 上移、下移或拖动调整顺序
- 切换 50%、75%、100% 宽度
- 左对齐、居中、右对齐
- 按 `Delete` 删除选中的图片，保留周围文字和其他图片

这些调整也会自动保存。

## 复制到公众号

顶部工具栏分别提供 `复制标题` 和 `复制到公众号`。

复制正文时，编辑器会整理文字排版、表格与图片，让图片宽度适应公众号正文。粘贴到公众号编辑区后，可以继续预览和微调。

## 连接账号，创建第一篇草稿

### 准备公众号信息

在公众号后台取得 AppID、AppSecret，确认草稿接口权限，并将当前电脑的公网 IP 加入白名单。

点击编辑器里的 `推送到草稿箱`，填写账号信息，再点 `保存账号设置`。这个按钮会验证连接并保存设置。

`检查账号连接` 用于单独确认接口是否可用，现有配置保持不变。

### 保存你的发布习惯

账号设置可以记住默认作者、阅读原文链接和评论开关。每次打开发布面板会自动填入，当前文章也能临时调整。

阅读原文链接对应公众号文章底部的跳转入口，可以填写项目地址、博客文章或资料页。没有外链需求时留空即可。

面板省去了手填摘要这一步，微信会按默认规则处理文章摘要。

### 选好封面，送进草稿箱

标题会从当前文章自动带入，作者、链接和评论设置会加载已保存的默认值。文章目录里的封面会自动识别，也可以手动选择 PNG 或 JPEG 图片。

定稿后点击 `创建草稿`，编辑器会整理排版、上传正文图片和封面，并将文章保存到草稿箱。随后到公众号后台预览内容、按文章实际情况设置原创声明，再完成发布。

## 封面怎么准备

准备好 PNG 或 JPEG 封面，可以放在文章目录中自动识别，也可以在发布面板中手动选择。

将封面放在文章目录里，发布器会按下面的顺序寻找。

1. 版本号最高的 `公众号封面-v*.png`、`.jpg` 或 `.jpeg`
2. `公众号封面.png`、`公众号封面.jpg` 或 `公众号封面.jpeg`

在发布面板中重新选择图片，可以替换自动识别的封面。正文图片使用 PNG 或 JPEG，超过上传尺寸要求时会调用 Pillow 压缩。

## 直接启动本地编辑器

也可以从 PowerShell 打开指定 HTML。以下命令在项目根目录运行。

```powershell
$plugin = Resolve-Path ".\plugins\wechat-publishing-workflow"
$launcher = Join-Path $plugin "skills\wechat-html-editor\scripts\start_editor.ps1"
& $launcher -Article "C:\文章\我的文章.html" -Open
```

启动器从 `17863` 开始寻找可用端口，启动后台进程并打开页面。输出的 JSON 会给出访问地址和进程 ID。

## 文件与账号信息

HTML 和图片保存在本地，编辑页面运行在 `127.0.0.1`。保存时会先写入临时文件，再替换原文件。

AppID 和常用发布设置作为本地配置保存，AppSecret 使用 Windows DPAPI 加密。账号配置目录如下。

```text
%LOCALAPPDATA%\wechat-draft-publisher
```

换电脑后，在新电脑上重新填写账号信息即可。分发项目时，使用打包脚本输出的压缩包，个人凭据和运行缓存会被排除。

## 常见问题

| 提示 | 怎么处理 |
| --- | --- |
| `40164` | 将当前公网 IP 加入公众号白名单 |
| `48001` | 在公众号后台检查草稿接口权限 |
| `40125` | 重新填写有效的 AppSecret |
| 封面未找到 | 在发布面板中选择 PNG 或 JPEG 图片 |
| 技能未出现 | 新建 Codex 任务，或重启 Codex 刷新技能列表 |

## 测试与打包

回归测试覆盖编辑器启动、自动保存备份、账号设置、草稿数据和发布包清单。

```powershell
python -m unittest discover -s ".\plugins\wechat-publishing-workflow\tests" -v
python .\scripts\package_release.py
```

测试使用示例文章、模拟接口和独立的本地进程。发布包输出到 `dist`，同时附带 SHA-256 校验文件。

安装验证采用本机新建的 Python 虚拟环境、Codex 配置目录和空凭据目录，覆盖从解压、安装到启动编辑器、保存文章的过程。其他 Windows 电脑与真实公众号权限，可在各自环境中继续验证。

## 卸载

移除插件。

```powershell
codex plugin remove wechat-publishing-workflow@personal
```

确认插件集已无其他在用插件后，可移除它的登记。

```powershell
codex plugin marketplace remove personal
```

账号配置会保留在本地，下次安装后可以继续使用。
